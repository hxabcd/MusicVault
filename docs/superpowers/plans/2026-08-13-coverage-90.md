# 覆盖率优化至 90%+ 实施计划（并行 subagent）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 排除交互代码后总体行覆盖率 ≥ 90%（当前 74%），并设置 `fail_under = 90` 防回归。

**Architecture:** 按文件集不重叠的 5 个批次并行 subagent 补测试；生产代码仅做行为不变的依赖注入/提取纯函数；交互函数（`input()`、二维码登录）标注 `# pragma: no cover` 排除统计；收尾统一配置 coverage 门槛。

**Tech Stack:** pytest 9+、pytest-cov 7+、Python 3.12（`.venv/Scripts/python.exe`）、ruff。

## Global Constraints

- 测试运行一律用 `.venv/Scripts/python.exe`（系统 python 3.13 缺 imghdr，导入 ncmdump 失败）。
- 中文 docstring 与注释；ruff line-length=120。
- 不得修改现有 `tests/` 文件、`pyproject.toml`、批次范围外的 src 文件。
- 生产代码只允许可测性小改（依赖注入、提取纯函数），行为不变。
- 不得添加 `# pragma: no cover`（收尾统一做）。
- 不运行 `--cov-report=annotate`（并行任务会互相覆盖 annotate 文件）；验证只跑 pytest 不带 `--cov`。
- 交互式流程（`input()`、二维码轮询、Rich prompt）无需测试，跳过。
